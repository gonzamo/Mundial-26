# 🏆 Mundial 2026 API

API REST para seguir y gestionar el **FIFA World Cup 2026**, desarrollada con Java y Spring Boot como proyecto personal de aprendizaje.

---

## ¿Qué es esta app?

Una aplicación backend que permite consultar y gestionar toda la información del Mundial 2026: equipos, jugadores, partidos, grupos y estadios. Incluye autenticación, documentación automática y una base de datos real con los 48 equipos clasificados.
